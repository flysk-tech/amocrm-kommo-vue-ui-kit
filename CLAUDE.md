# Проект: amoCRM Vue UI Kit

## Цель проекта
Создание Vue.js 3 версии React библиотеки `@kommo-crm/crm-react-ui-kit` с адаптацией под amoCRM и русской локализацией.

## Важные принципы разработки

### 🔄 Максимальное переиспользование кода
- **ВСЕГДА** копировать оригинальный код из React библиотеки
- **НЕ ИЗОБРЕТАТЬ ЗАНОВО** - использовать существующие стили, логику и структуру
- Адаптировать только синтаксис для Vue.js 3, сохраняя поведение и API

### 📁 Структура проекта
```
src/
├── components/         # Vue компоненты (аналоги React компонентов)
│   ├── Button/        # ✅ ГОТОВ - первый UI компонент
│   ├── Spinner/       # ✅ ГОТОВ - вспомогательный компонент
│   └── ...           # TODO: остальные 22 компонента
├── composables/       # Vue композиционные функции (аналоги React хуков)
├── types/            # TypeScript типы
├── utils/            # Утилиты
└── styles/           # SCSS стили с CSS переменными
```

### 🎯 Архитектура CSS переменных и тем
**Статус:** ✅ ЗАВЕРШЕН

**Правильная структура (как в React оригинале):**
1. ✅ `src/styles/theme.css` - только базовые цвета и глобальная палитра
2. ✅ `Component.themes.ts` - специфичные CSS переменные для каждого компонента
3. ✅ `Component.module.scss` - использует переменные через var()
4. ✅ `theme` prop опциональный - если не передан, используются глобальные переменные

### 🛠 Технический стек
- **Vue 3** + Composition API + `<script setup>`
- **TypeScript** с строгой типизацией
- **Vite** для сборки и dev сервера
- **SCSS** с CSS модулями
- **CSS переменные** для системы тем
- **Композиционные функции** вместо React хуков
- **Storybook 9** для документации (исходная React библиотека использует Storybook 8)
