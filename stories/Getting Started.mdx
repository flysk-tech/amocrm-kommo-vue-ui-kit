    ## Пример использования

    Базовый пример работы с компонентами библиотеки:
  </div>

```vue
<template>
  <div>
    <Input
      v-model="inputValue"
      :theme="InputPrimaryTheme"
      placeholder="Введите текст"
      :isInvalid="isError"
      invalidDescription="Поле обязательно для заполнения"
    >
      <template #after>
        <svg style="width: 16px; height: 16px;"><!-- иконка --></svg>
      </template>
    </Input>

    <Button
      :theme="ButtonPrimaryTheme"
      @click="handleSubmit"
    >
      Отправить
    </Button>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import { Button, ButtonPrimaryTheme } from '@amocrm/vue-ui-kit/Button'
import { Input, InputPrimaryTheme } from '@amocrm/vue-ui-kit/Input'

const inputValue = ref('')
const isError = ref(false)

const handleSubmit = () => {
  if (!inputValue.value) {
    isError.value = true
  } else {
    console.log('Значение:', inputValue.value)
    isError.value = false
  }
}
</script>
```
